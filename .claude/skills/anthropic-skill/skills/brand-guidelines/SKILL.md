## 概述

提供 Anthropic 官方品牌的顏色代碼與字體規範，用於對任何 artifact 套用一致的品牌視覺識別。

## 能做什麼

- 提供精確的 Anthropic 品牌色彩，包含 RGB 與 Hex 值。
- 指定標題與正文的字體規範。
- 對 PPTX、HTML、PDF 等 artifact 套用品牌樣式。
- 在沒有首選字體時提供合理的退回字體。

## Anthropic 品牌規格

### 顏色

- `Dark` -> `#141413` -> 主要文字與深色背景。
- `Light` -> `#faf9f5` -> 淺色背景與深色背景上的文字。
- `Mid Gray` -> `#b0aea5` -> 次要元素。
- `Light Gray` -> `#e8e6dc` -> 細微背景。
- `Orange` -> `#d97757` -> 主要強調色。
- `Blue` -> `#6a9bcc` -> 次要強調色。
- `Green` -> `#788c5d` -> 第三強調色。

### 字體

- 標題（24pt+）使用 `Poppins`；如果不可用，退回 `Arial`。
- 正文使用 `Lora`；如果不可用，退回 `Georgia`。

## 重要注意事項

- 字體必須先安裝在環境中，才能獲得最佳效果。
- 非文字形狀優先使用強調色循環。
- 此 skill 不負責設計創作；它只提供品牌規格參考。
