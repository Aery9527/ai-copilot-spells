# 學術測試：Systematic Debugging Skill

你可以使用 `skills/debugging/systematic-debugging` 中的 systematic debugging skill。

請閱讀此 skill，並**只根據 skill 的內容**回答以下問題：

1. 系統化除錯的四個階段是什麼？
2. 在嘗試任何修復之前，你必須做什麼？
3. 在第三階段，若你的第一個假說無效，該怎麼做？
4. 關於同時修復多件事，skill 是怎麼說的？
5. 若你不完全理解問題，該怎麼做？
6. 對於簡單錯誤，跳過流程是否可接受？

請在適用之處，直接引用 skill 的原文作為回答依據。
