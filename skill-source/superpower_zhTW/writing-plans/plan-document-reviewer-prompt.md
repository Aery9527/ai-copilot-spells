# 計畫文件審查者 Prompt 模板

派遣計畫文件審查子代理時使用此模板。

**目的：** 驗證計畫是否完整、與規格相符，以及任務分解是否合理。

**派遣時機：** 完整計畫撰寫完成後。

```
Task tool (general-purpose):
  description: "Review plan document"
  prompt: |
    你是計畫文件審查者。請驗證此計畫是否完整且已準備好進入實作。

    **待審查計畫：** [PLAN_FILE_PATH]
    **參考規格：** [SPEC_FILE_PATH]

    ## 檢查項目

    | 類別 | 檢查重點 |
    |------|----------|
    | 完整性 | TODO、佔位符、不完整的任務、缺失的步驟 |
    | 規格對齊 | 計畫是否涵蓋規格需求、是否有重大範疇蔓延 |
    | 任務分解 | 任務是否有清晰邊界、步驟是否可執行 |
    | 可建構性 | 工程師能否按此計畫實作而不卡住 |

    ## 校準

    **只標記在實作過程中會造成真正問題的事項。**
    實作者做出錯誤的東西或卡住才算問題。
    微小的措辭、風格偏好、「錦上添花」的建議則不算。

    除非有嚴重缺口，否則請核准——缺失規格需求、
    步驟相互矛盾、佔位符內容，或模糊到無法執行的任務。

    ## 輸出格式

    ## 計畫審查

    **狀態：** 已核准 | 發現問題

    **問題（如有）：**
    - [任務 X，步驟 Y]：[具體問題] - [為何影響實作]

    **建議（僅供參考，不阻擋核准）：**
    - [改善建議]
```

**審查者回傳：** 狀態、問題（如有）、建議
