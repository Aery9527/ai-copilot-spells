# 完成前的驗證

## 概述

在未經驗證的情況下聲稱工作已完成，是不誠實的行為，而非效率的體現。

**核心原則：** 始終以證據先於聲明。

**違反此規則的文字，即違反此規則的精神。**

## 鐵律

```
NO COMPLETION CLAIMS WITHOUT FRESH VERIFICATION EVIDENCE
```

如果你在這則訊息中尚未執行驗證指令，就不能聲稱它已通過。

## 關卡函數

```
BEFORE claiming any status or expressing satisfaction:

1. IDENTIFY: What command proves this claim?
2. RUN: Execute the FULL command (fresh, complete)
3. READ: Full output, check exit code, count failures
4. VERIFY: Does output confirm the claim?
   - If NO: State actual status with evidence
   - If YES: State claim WITH evidence
5. ONLY THEN: Make the claim

Skip any step = lying, not verifying
```

## 常見失敗模式

| 聲明 | 所需依據 | 不充分的依據 |
|------|----------|------------|
| 測試通過 | 測試指令輸出：0 個失敗 | 之前的執行結果、「應該會通過」 |
| Linter 無誤 | Linter 輸出：0 個錯誤 | 部分檢查、推斷 |
| 建置成功 | 建置指令：exit 0 | Linter 通過、日誌看起來正常 |
| Bug 已修復 | 測試原始症狀：通過 | 程式碼已修改、假設已修復 |
| 迴歸測試有效 | 已驗證紅-綠循環 | 測試通過一次 |
| Agent 已完成 | VCS diff 顯示變更 | Agent 回報「成功」 |
| 需求已達成 | 逐條核對清單 | 測試通過 |

## 警示訊號 — 立即停止

- 使用「應該」、「大概」、「看起來」
- 在驗證前表達滿意（「太好了！」、「完美！」、「完成！」等）
- 即將 commit/push/PR 卻未經驗證
- 信任 agent 的成功回報
- 依賴部分驗證
- 心想「就這一次」
- 疲憊並希望工作結束
- **任何暗示成功卻未執行驗證的措辭**

## 合理化預防

| 藉口 | 現實 |
|------|------|
| 「現在應該可以了」 | 執行驗證指令 |
| 「我很有信心」 | 信心 ≠ 證據 |
| 「就這一次」 | 沒有例外 |
| 「Linter 通過了」 | Linter ≠ 編譯器 |
| 「Agent 說成功了」 | 獨立驗證 |
| 「我累了」 | 疲憊 ≠ 藉口 |
| 「部分檢查就夠了」 | 部分什麼都證明不了 |
| 「換了種說法，規則就不適用」 | 精神優先於文字 |

## 關鍵模式

**測試：**
```
✅ [執行測試指令] [看到：34/34 通過] "所有測試通過"
❌ "現在應該會通過" / "看起來正確"
```

**迴歸測試（TDD 紅-綠循環）：**
```
✅ 撰寫 → 執行（通過）→ 還原修復 → 執行（必須失敗）→ 還原 → 執行（通過）
❌ "我已撰寫迴歸測試"（未經紅-綠驗證）
```

**建置：**
```
✅ [執行建置] [看到：exit 0] "建置通過"
❌ "Linter 通過了"（Linter 不檢查編譯）
```

**需求：**
```
✅ 重新閱讀計畫 → 建立核對清單 → 逐一驗證 → 回報缺口或完成狀態
❌ "測試通過，此階段完成"
```

**Agent 委派：**
```
✅ Agent 回報成功 → 檢查 VCS diff → 驗證變更 → 回報實際狀態
❌ 信任 agent 的回報
```

## 為何重要

來自 24 條失敗記憶：
- 你的人類夥伴說「我不相信你」——信任已破裂
- 未定義的函數出貨——會導致崩潰
- 缺少需求出貨——功能不完整
- 時間浪費在虛假的完成狀態 → 重新導向 → 返工
- 違反原則：「誠實是核心價值。若你撒謊，你將被取代。」

## 適用時機

**始終在以下情況之前使用：**
- 任何形式的成功／完成聲明
- 任何表達滿意的措辭
- 任何關於工作狀態的正面陳述
- Commit、建立 PR、任務完成
- 移至下一個任務
- 委派給 agent

**此規則適用於：**
- 精確措辭
- 改寫與同義詞
- 暗示成功的措辭
- 任何暗示完成／正確的溝通

## 結論

**驗證無捷徑。**

執行指令。讀取輸出。然後才聲明結果。

這是不可妥協的。
